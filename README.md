# 卡牌传奇 Card Legend Proto

横版实时卡牌动作 RPG 网页原型（Phaser 3 + TypeScript + Vite）。三职业、5 层地牢 + 每层首领、装备背包、商人、等级成长、存档。

> ⚠️ **魔兽素材仅供个人原型，公开前必须替换。** 技能/物品/药水图标、UI 贴图、音效导出自《魔兽世界》1.12.1 客户端，版权归暴雪娱乐所有。

## 运行
```bash
npm install
npm run dev      # vite --host --port 5180
npm test         # 逻辑单测 + 三职业自动通关模拟（node + tsx）
npm run build    # tsc --noEmit + vite build → dist/
```
- 本机：http://127.0.0.1:5180/
- 局域网：http://192.168.2.7:5180/（同一 Wi-Fi 下的手机/电脑可访问；IP 变了用 `ipconfig getifaddr en0` 查看）

## 操作
| 按键 | 作用 |
|---|---|
| ← → / A D | 左右移动；↑ ↓ 纵深 |
| Q W E R | 职业技能（悬停/按 K 看说明） |
| 1 2 3 4 | 小/中 金创药，小/中 魔法药 |
| B / C / I | 角色 + 背包面板（打开时战斗暂停） |
| F | 与本层起点的商人交易（买药、卖装备）；也可点击商人小摊 |
| K | 技能面板 |
| Esc | 设置（音量、静音、保存并返回标题） |
| M | 静音开关 |
| 鼠标 | 背包：左键装备、右键丢弃、悬停看属性；装备栏左键卸下；商店模式左键出售 |

## 系统
- **职业**（标题 → 新游戏 → 选职业，卡底色：战士深灰 / 法师蓝 / 道士金黄）
  - 战士：烈火剑法、半月弯刀（穿透 3 个）、暗影斩击、金刚护体（减伤 50%）
  - 法师：火球术（远程弹道）、雷电术、冰咆哮（范围伤害 + 减速）、魔法盾（减伤 40%）
  - 道士：灵魂火符（远程符纸）、施毒术（每秒掉血）、召唤骷髅（金色卡底友方单位，跟随主角作战，跨层保留）、神圣战甲术（减伤 + 回血）
- **成长**：击杀得经验，升级按职业成长自动加属性并回满；技能伤害 = 主属性 × 倍率 × (1 + 0.02×(等级-1))
- **装备**：7 个部位（武器/头盔/衣服/项链/戒指/手镯/靴子），普通/精良/极品三档随机词条，有需求等级；掉落自动拾取进背包（30 格，满了不拾取）
- **商人**：每层起点；买 4 种药水、按售价出售背包物品
- **地牢**：5 层（幽暗森林 / 蛛网晶洞 / 白骨墓穴 / 兽人要塞 / 尸王殿），每层不同背景、怪物组合和首领；首领未死出口封印
- **死亡**：3 秒后在本层起点复活，损失 10% 金币，本层怪物重置
- **存档**：localStorage（`fcl_save_v1`），进层/升级/交易/装备/每 15 秒自动存；标题“继续”读取；通关后清除。设置存 `fcl_settings_v1`
- **表现**：攻击时卡牌突进、受击闪色 + 震动、伤害数字飘字、暴击金色放大 + 轻微震屏；排队的怪物仅在渲染层错开，不改变战斗逻辑
- **声音**：点击/拾取/金币/升级/技能/受击/死亡音效；**没有背景音乐**（素材库中找不到 BGM ogg）

## 调试 / 截图参数
`?class=mage|taoist|warrior` 跳过标题直接开局，`&floor=N` 第 N 层，`&lv=N` 等级，`&demo=1` 把怪物摆到主角身边，`&summon=1` 先召唤骷髅，`&gear=1` 塞一批装备，`&panel=bag|shop|skills|settings` 打开面板，`&cast=Q` 开局释放技能，`&boss=1` 只摆首领。`?title=class` 直接显示职业选择。

## 目录
- `src/combat/World.ts` 纯 TS 世界逻辑（职业、技能、召唤、背包/装备/商店、经验、存档、复活），无 Phaser 依赖
- `src/data/` classes（职业/技能）、units（怪物）、items（装备）、world（地图参数、5 层配置）
- `src/scenes/` Title（加载/标题/职业选择/设置）、Battle（战斗渲染）、UI（HUD + 面板）
- `src/ui/` CardView 卡牌、Fx 特效、Hud、Panel（背包/商店/技能/设置）
- `tests/battle.test.ts` 59 项断言，含三职业自动通关 5 层模拟

## 手机游玩（横屏 + 虚拟按键）

- 手机/平板浏览器打开 `http://<电脑IP>:5180/` 即可；自动识别触屏设备（可用 `?mobile=1` / `?mobile=0` 强制）。
- 竖屏时显示"请把手机横过来"遮罩；点击遮罩会尝试全屏并锁定横屏（Android Chrome 支持；iPhone Safari 不支持锁定，需关闭竖排方向锁定后旋转，或"添加到主屏幕"）。
- 半透明虚拟按键（仅手机显示，电脑不显示）：左下方向键（左右移动、上下纵深）；右下 Q/W/E/R 技能（带图标和冷却转圈）；右上 1–4 药水；顶部 背包/商人/设置/静音。支持多点触控，与键盘走同一输入逻辑。
- 背包/商店在手机上：点一下选中查看属性，再点一次装备/卸下/购买/出售。
- 设置里可开关"虚拟按键"和"低特效"（手机默认开启低特效：减少粒子、关闭震屏）。
