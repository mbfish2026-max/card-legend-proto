# 世界大地图重做方案（WoW 式：世界总图 → 区域图 → 节点传送）
状态：**只出方案**，未改代码。分支建议：并入 feat/towns 之后单开 `feat/world-map`（基于 feat/multi-save，探索状态要按槽存）。不合 main、不发布。

## 0. 分工（避免与「地图总览/位置条」重复）
| 入口 | 内容 | 范围 |
|---|---|---|
| 右上角层名 → 地图总览（已做，docs/map-overview.md） | 本层：名称、第 N/总层、推荐等级、BOSS/精英/怪、左右出口、位置条 | **本层信息** |
| HUD「地图」按钮 / M 键 → 世界地图（本方案） | 全大陆：区域、城镇、地图群、连接线、迷雾、传送 | **全局导航** |
总览面板底部加一个「在世界地图中查看」按钮，跳到世界地图并定位到当前区域节点（唯一的交叉点）。

## 1. 交互（参考魔兽世界地图模式）
1. **世界总图**：一张连续大陆底图（4096×2304 逻辑，见 §3），8 个区域多边形热区，每区：固定位置、名称、推荐等级段（如「盟重省 Lv19–40」）、区域主色描边；城镇用城堡图标；区域间连接用道路/海路虚线（苍月岛 = 海路，魔龙/合击 = 「老兵传送」虚线）。
2. **点区域 → 区域图**：镜头放大过渡（0.35s）到该区域插画，显示各层/子图节点（洞穴/副本/城镇/出口图标）、节点间连接线（按 `prevFloorOf/nextFloorOf` 与 group 深度）、**当前位置**（玩家头像标记，脉冲）、**BOSS 标记**（骷髅图标；已击杀 `bossKilled` 灰化，冷却中显示倒计时）。多层地图群默认收拢为 1 个节点「兽人古墓 1–3 层」，点开展开成竖排子节点（83 层这样展示不拥挤，见 §2）。
3. **点节点 → 传送**：弹确认卡（层名、推荐等级、费用、冷却），沿用现有规则 `World.canTeleport`：需 `reached`、非战斗、30s 冷却、`(i+1)*20` 金币；城镇节点 = 回城（回城卷/老兵规则不变）。不可传送时给原因（复用 canTeleport 返回文案）。
4. **迷雾**：区域内一个层都没到过 → 整区迷雾（只显示轮廓+「？？？」，等级段可见以便规划）；到过任一层 → 区域点亮；节点逐个点亮（未到 = 暗色问号节点，连接线虚化）。
5. **手机 844×390**：单指拖动、双指缩放（0.5–2.5×）、双击区域进入；返回按钮/关闭/传送按钮 ≥44px；节点标签 ≥12px（画布缩放 0.54 → 逻辑字号 ≥24），缩小时标签按优先级隐藏（城镇 > 当前 > BOSS > 其他）。桌面 1280×720：滚轮缩放、拖动、悬停显示节点提示。
6. Esc/返回：区域图 → 世界总图 → 关闭。

## 4. 技术方案
### 4.1 数据结构（扩展 src/data/map.ts，不破坏现有 Region/MapNode）
```ts
export interface RegionGeo {
  id: string;                 // = Region.id
  color: number;              // 区域主色（描边/标签）
  poly: [number, number][];   // 世界总图热区多边形（底图像素坐标 4096×2304）
  label: [number, number];    // 名称/等级段锚点
  art: string;                // 区域插画 key（world_region_<id>.jpg）
  links: { to: string; kind: 'road' | 'sea' | 'npc'; src?: string }[]; // 官方连接；npc=老兵传送
}
export interface NodeGeo { node: string; x: number; y: number; group?: string; collapse?: boolean } // 区域插画内像素坐标（取代现 0–1 比例，旧比例×插画尺寸自动换算）
export const REGION_GEO: Record<string, RegionGeo> = { /* … */ };
```
等级段由 `FLOOR_TARGET_LV` 计算，不手填；连接线由 `prevFloorOf/nextFloorOf/FLOOR_GROUP` 生成，只有跨区连接手填在 `links`。

### 4.2 探索状态（存档）
- 不新增字段：**已探索层 = 现有 `save.reached`**；区域点亮 = 区域内任一层 ∈ reached；城镇点亮 = 去过（新增 `townsSeen?: string[]`，可选字段，缺省按 reached 推：区域点亮即其城镇点亮）。
- 旧档迁移：reached 已存在 → 自动生效，「已去过的层视为已探索」无需迁移代码；仅加测试保证。
- 多存档：reached/townsSeen 在角色存档内 → 天然按槽隔离（feat/multi-save 的槽数据）；地图缩放/上次查看区域属全局设置（Settings，不按槽）。

### 4.3 复用
- 传送：`World.canTeleport/teleport/teleportCost` 原样；传送员/老兵 NPC 的列表面板（已做虚拟滚动）保留为「文字列表」备选入口，同一数据源 `REGIONS`。
- 现有 `Panel.renderMap`（mode 'map'，WORLD_W 2400×1400 拖动缩放）改为两级：总图 → 区域图；拖动/缩放代码复用，手机端沿用 Panel 的 mscale 逻辑。
- 地图总览：加「在世界地图中查看」按钮。

### 4.4 测试与验证
- 单测：83 层都有区域与节点坐标；每个 RegionGeo.links 双向一致；迷雾规则（空 reached 全雾、reached=[0] 仅比奇亮）；节点传送调用 canTeleport 且文案一致；旧档（无 townsSeen）加载不崩；多存档两槽探索互不影响。
- e2e：844×390 / 1280×720 打开世界图 → 点区域 → 点节点 → 确认传送 → 层切换；拖动/双指缩放；字号 ≥12px、按钮 ≥44px、无溢出；截图 world-map-*.png。
