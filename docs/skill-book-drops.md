# 技能书 BOSS 掉落表（R54）

规则：商店（含原「传世秘籍」页）只卖学习等级 ≤25 的书；>25 级书一律由 BOSS 掉落。
- 26–35 级：只由「尸王」(boss_lich) 及以上 BOSS 掉落，尸王掉率最高（尸王 10%，另一个层等级≈书等级的 BOSS 5%）。
- >35 级：由所在层等级≈书等级（±3）的高级 BOSS 掉落（8%；Lv40+ 书由双头金刚/双头血魔各 8%）。本作最高 BOSS 层等级 40，所以 Lv41/42 的书只能映射到 40 级层。
- 「层等级」= 该层怪物最高等级（本作没有单独的推荐等级字段，用它代替）。
- 掉率标注：**适配** = 官方无对应数据，按上述规则设定；括号内给出能查到的 21cq 原尸王爆率作参考。具体掉落 BOSS 的官方来源全部 **未查到**（原版这些书多为多怪随机掉落，没有本作 BOSS 对应关系）。
- 每次击杀只对本职业、未学会、背包里没有的书判定；只有表里的 BOSS 会额外消耗掉落随机数。
- 数据：src/data/skillBookDrops.ts；掉落接入在 World.kill()。旧档：已学技能与背包里的书都不受影响。
