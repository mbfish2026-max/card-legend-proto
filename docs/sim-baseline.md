# fix/sim-baseline：sim 死亡口径与通过基线

只改 sim/测试/文档（tests/sim-lib.ts、scripts/sim-bands.ts、tests/battle.test.ts），不动 FOE_BAND 和任何游戏数值。结果文件：/workspace/cl-balance-sim/sb/（main = a6a9afa 导出，new = 本分支导出）。

## 1. 口径选择：「无损失死亡」单独计数（不设购物金币下限）

| 方案 | 对 sim 轨迹的扰动 |
|---|---|
| 购物金币下限 | 改变何时买药/买书 → 从第一次死亡起轨迹分叉；当前 main 1–39 级段中位死亡 1–3 次，几乎每个种子 Lv<40 就有死亡 → 1–39 指纹必然变；下限取值也是新的模拟参数 |
| **无损失死亡单独计数（采用）** | 只读统计，零扰动：总死亡、逐种子、段分布、1–39 指纹与 main 完全相同（实测 27/27） |

- 判定方法是实测，不写死：sim-lib 在 respawn 前后比较金币、经验、等级、背包件数、装备件数，全不变记「无损失」，否则记「有损失」。no-death-drop 后所有死亡都是无损失；以后如果重新加死亡惩罚，会自动进入有损失计数。
- PASS_MAX_DEATHS = 14 不变，卡**每种子有损失死亡**（硬断言）。
- 无损失死亡按下表新基线报告（`want`，超出列 GAP，不放宽）。
