# CHANGELOG

## R9 — 画面缩放「自适应」（2026-10-31）
- 设置（SettingsView，标题与游戏内共用）画面缩放新增「自适应」：按视口扣除安全区后等比 FIT（min(宽/1280, 高/720)），整幅横屏完整显示、尽量填满、不裁切不失真；面板显示实际比例。
- 手机默认自适应（`zoomAuto=null` → 手机开/电脑关）；80~120% 预设与 ± 保留为手动，选中即退出自适应。
- resize / orientationchange / visualViewport 变化实时重算（补 120ms/400ms 两次，应对 iOS 旋转延迟）。
- 验证（Puppeteer 触屏 tap）：667×375 → 画布 667×375（52%）；844×390 → 693×390（54%）；932×430 → 764×430（60%）；iPad 1024×768 → 1024×576（80%）。均完整在视口内、比例 16:9、一边填满；切 110% 后再点自适应恢复；游戏内点 HUD「设置」命中正确；旋转竖屏再转回后尺寸恢复。截图 `screenshots/r9/`。
