# 装备掉落地点审计（drop-audit）

> 范围：只审计并提出方案，本分支没有改任何游戏代码。数据来源是 `scripts/drop-audit-dump.ts`（只读脚本，导入 World 后读取最终 ENEMIES，按层导出 TSV），本次导出共 1740 行。
> 资料来源：21cq.com「1.76 热血传奇」数据库（玩家复原数据，不是盛大发布的数据，见 docs/drops-official.md）。标「未查到」的条目表示没有找到资料。「适配」表示本作自己的改编。
> 链接写法：物品页 `https://www.21cq.com/mir/View.aspx?id=<cq>`，怪物页 `https://www.21cq.com/mir/Mob.Aspx?ID=<n>`。

## 0. 爆率约定（需要先说明的事实）
- 任务约定的本作爆率换算是：官方 1/N → 本作 1/(N/40)。
- **现状并不统一**：R13 的 `officialDrops`（drops.ts，13 层主线怪的装备掉落）用的是官方 1/N 原值，没有乘 40。docs/drops-official.md 写的是「1/N（不加成）」。只有 `EG_DROPS`（drop-plan.ts，40 级以上装备）按 ÷40 换算。`HJ_GEAR` 的 1/40、1/60、1/30 是适配值，跟官方 N 没有对应关系。`WOMA_S9` 用的倍率是 K=4。
- 决策 D1 讨论是否把 ÷40 统一到主线（见第 5 节）。下文提到「÷40 后」的数值都是建议值。
- BOSS 首杀必出、之后概率 ÷10（`DUNGEON_FIRST_GUARANTEE`，dungeons.ts）：这里只记录，本审计不改。

## 5. 需要用户拍板的决策（带推荐）
- D1 主线 R13 是否统一 ÷40？推荐：**暂不统一**。先完成 F1–F7 的地点修正，等 E5 评估后再定。

- D3 兽人酋长的重盔甲、金戒指保留吗？推荐：保留（R2 存量，1–39 级保持现状），在文档里标为适配。

- D6 三圣池是否从赤月恶魔移到双头血魔？推荐：移（赤月恶魔保留屠龙等官方来源）。
