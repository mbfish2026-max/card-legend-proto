状态：方案文档，未改代码。2026-10-31，feat/balance-sys。
规则：坐标、NPC 都附来源；查不到的写「未查到」；我们自己定的写 [适配]。

## 0. 不变的规则（与任务B传送门、任务C回城卷轴一致）

- 城里是安全区，没有怪，不能战斗。**商人只在城里**，野外地图不放商人（战斗地图左端只放「返回上一层」传送门）。
- 回城卷轴 / 回城：回到**当前楼层所属区域的主城**，即 `returnTownOf(floor)`。先看哪座城的 `exit` 等于这一层，再按 `REGIONS` 找本区域的 town 节点。
- 新城接入后，回城卷轴的去向表（[适配]）如下：

  | 区域（src/data/map.ts） | 回到 |
  |---|---|
  | 比奇省（第 1 层 = 新手区） | 银杏村 / 比奇城（现状不变） |
  | 沃玛森林 | 比奇城。沃玛有没有城内商店，未查到（见 §1.5），先不单做城。 |
  | 盟重省 | 盟重土城 |
  | 白日门·赤月峡谷 | 白日门 |
  | 封魔谷 | 封魔谷据点 |
  | 苍月岛 | 苍月岛 |

- 传送门：区域首层左端的门 =「传送门：返回 <本区域主城>」。其它层左端的门回上一层。
- 城内老兵 / 传送员：列出全部已到达楼层，列表可滚动（见 CHANGELOG「城内 NPC 长列表可滚动」）。

## 2. 横版长街布局（对照现有银杏村 / 比奇城）

### 现状

`src/data/towns.ts`：
- 街宽 = 3 屏（STREET_ART_K：素材 5760×1080，缩放到 3840×720）。
- 西端是城门（出城），店铺门面沿街等距排开，走到门口出现 NPC。

### 布局规则（[适配]）

- 按原版 x 坐标从西到东排店铺。
- 老兵 / 传送员放在城门旁边。
- 药店、武器店离城门近，常用的放前面。
- 每屏最多放 3 个门面。

| 城 | 屏数 | 门面顺序（西→东） | 备注 |
|---|---|---|---|
| 盟重土城 | 4 | 城门·盟重老兵｜杂货(罗家铺子)·杂货店｜仓库(王家)·客栈｜武器店·服装·首饰｜炼金师·肉店·药店｜书店·牢房守卫(装饰) | 门面 12 个左右 → 4 屏；沙巴克城门作为东端装饰（攻城玩法不做） |
| 白日门 | 3 | 城门·向导｜神秘书商·武器店｜仓库·药店｜首饰·服装｜神秘铁匠·龙人（已有 brm_dragon） | 官方坐标大多未查到，顺序 [适配] |
| 封魔谷据点 | 2 | 城门·老兵｜药店·武器店｜仓库·杂货 | NPC 未查到，先只放 basic() 那几家 |
| 苍月岛 | 2 | 码头(城门)｜武器·杂货｜仓库·服装·药店｜首饰·书店 | 坐标未查到，顺序 [适配] |
| 比奇城 / 银杏村 | 已有 | — | 不动 |

### 建议先做

1. **盟重土城**：
   - 盟重省区域在 `REGIONS` 占 32 层，是游戏中段最长的一段；回城、补给最频繁。
   - 官方 NPC 坐标齐全。
2. **白日门**：
   - 已有龙人 / 合击 NPC，后期常回。
   - 官方有 NPC 清单（坐标不全）。
3. 封魔谷、苍月岛：NPC 资料缺，先沿用 basic() 的通用街景，等美术。

传世 / 传奇3 主城只作命名和店铺种类参考，不进本作地图。本作是热血传奇 1.76 体系。
