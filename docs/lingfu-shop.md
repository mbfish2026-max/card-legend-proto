# 灵符商城方案（feat/lingfu-doc，仅文档）

> 用户原话：「增加一个灵符商城，灵符商城里面出售召唤物7级直升卷轴，还有各种氪金物品，然后增加一个货币为灵符，1块钱10个灵符，新账号里面默认5000灵符」；「灵符商店还有技巧项链，佩戴后技能熟练度提升5倍」；「还有不同等级的血石，装备栏也多一个血石位置，佩戴后，血石里面存储了大量的红跟蓝，就会自动使用」；「商城里有回城石，没有施法时间可以直接回城」。
> 标注：**[官方]** 有来源；**[适配]** 本作自定；**未查到** 没找到依据。本文不改代码。
> 代码事实均读自 origin/main de138f5。

## 0. 结论

| 项 | 建议 |
|---|---|
| 灵符归属 | **账号级**（服务端钱包），游客模式为**本机级**单一钱包（不按存档槽） |
| 新账号赠送 | 5000 灵符，**只在服务端注册时发一次**；游客本机钱包首次创建发 5000，删槽/新建槽不再发 |
| 支付 | 本阶段**不接真实支付**；「充值」入口为占位，标注「未接入支付」；1 元 = 10 灵符只出现在价格展示 |
| 扣费 | 登录态：Edge Function `wallet` 单次事务完成「扣灵符 + 写流水 + 写订单」，客户端收到订单后发货；游客态：本机同一次 `SaveStore.write` 内扣款+发货 |
| 不卖 | 顶级/套装装备、祝福油（只由 BOSS 掉落）、黑铁矿石（只能挖矿） |
| 回归 | 9 seed sim 与 battle.test **默认不使用商城**：sim 不创建钱包、不调用商城 API；商品效果另写独立单测 |
| 账号后端 | 按魔兽最新决定：**建议新建独立 Supabase 项目**（不再复用 idle-arpg 的项目），等用户提供 URL + anon(publishable) key 后再联调，见 §9 |

## 1. 灵符货币

### 1.1 存档字段：账号级还是存档槽级
现状（已读 `src/settings.ts`）：多存档位，槽 1 沿用 `fcl_save_v1`，其余 `fcl_save_v1_s<n>`，元数据 `fcl_slots_v1`；设置 `fcl_settings_v1` 全局共享。

建议 **不放进 SaveData**（不按槽），理由：
1. 用户说「新账号默认 5000」，是账号概念，不是角色概念；
2. 按槽存会出现「删槽/新建槽再领 5000」的刷取漏洞；
3. 登录后余额以服务端为准（docs/account-db.md §5 的 `wallet`/`ledger` 表），存档槽只是云端副本，不应携带货币；
4. 导出/导入存档（现有功能）若带余额，等于可复制灵符。

字段设计：
- 游客：新键 `fcl_lingfu_v1 = { v:1, balance, granted:true, createdAt, ledger:[最近 50 条] }`（与存档槽无关）。
- 登录：余额只读缓存 `fcl_lingfu_cache_<uid>`，权威值在服务端 `fcl.wallet`。
- 购买得到的**物品**进对应存档槽（背包/装备），这部分属于角色，随槽走。

### 1.2 默认 5000 与旧档迁移、防重复赠送
| 场景 | 处理 |
|---|---|
| 新账号注册 | 服务端 on_signup 触发器写 `wallet.balance=5000` + `ledger(reason='signup_gift')`，`account_id` 唯一键保证只发一次（已在 account-p1 的 SQL 草案里） |
| 游客首次打开（无 `fcl_lingfu_v1`） | 建钱包并发 5000，`granted:true` |
| 旧存档玩家（升级后首次打开） | 视同游客首次：发一次 5000（旧档不按槽补发） |
| 删除存档槽 / 新建存档槽 | 不影响钱包，**不再发** |
| 导入存档 | 存档里不含余额，导入不改钱包 |
| 清空浏览器数据 | 本机钱包丢失，会重新发 5000 — **防不住**（见 §5），所以游客灵符只算「体验额度」 |
| 游客转登录 | 游客余额**不并入**账号（避免清缓存刷 5000 再并入）；账号用自己的 5000。待决项 P1 |

### 1.3 界面显示位置
- 桌面 1280×720：顶栏金币右侧，`lingfu_icon_s`(32) 显示 20px + 数字，不与 HP/MP 条和右上功能按钮重叠；商城面板标题栏右侧再显示一次。
- 手机 844×390：`MobileHud` 的 info 行（现为「职业 金币 N」，`MobileHud.ts:186`）追加「灵符 N」；不新增浮层，避免挡战斗区。
- 价格：`lingfu_icon_xs`(16) + 数字，旁注小字「≈ N 元」（N = 价格/10）。

### 3.1 召唤物 7 级直升卷轴
现有规则（已读 `World.ts`）：
- 召唤物等级 0–7（`SUMMON_MAX_LV=7`），初始 = 技能等级（最高 3），按召出后击杀数升级，累计阈值 `SUMMON_LV_KILLS=[0,10,25,45,75,115,165,225]` [适配]；道士骷髅/神兽与法师诱惑宠物共用这套规则与名字颜色（`summonLabel.ts`）。
- 召唤物强度再乘人物等级倍率 `summonMulAt`：`summonNerfLv=11` 起线性降到 `summonNerfFullLv=25` 时 ×0.3（`data/world.ts:37,59`）。
- 召唤物**不进存档**（SaveData 无此字段），换层/读档/重召都按技能等级重新开始。

设计建议：
- 作用对象 = **当前在场的召唤物**（不是技能）：使用后把 `sLv` 设为 7、`sKills` 设为 `SUMMON_LV_KILLS[7]`，走现有 `applySummonLv`，名字变最深蓝。
- **仍乘 `summonMulAt`**（人物等级倍率不绕过），所以高等级角色的 7 级宝宝依旧是 ×0.3 后的数值。
- 无召唤物/召唤物已 7 级时不可用、不扣费；法师诱惑宠物同样适用，但叛变计时（`CHARM.duration`）不变。
- 召唤物死亡/重召/换层后效果消失 —— 这是与「技能永久」方案的取舍：单次消耗更好控平衡。待决项 P2：是否改成「本次登录/本层持续」或「下次召唤直接 7 级 N 次」。
- 需要战斗开发：`World.boostSummon(uid, lv)` 接口；sim 中不调用。

### 3.2 技巧项链
- 现有熟练度机制**存在**：`SaveData.skillTrain`（按技能 id），`World.addTrain(s, n)`；施放 +100、被动 +10/+1 [适配]；技能等级由人物等级与 `train[k]` 阈值决定（`World.ts:188–199`）。
- [官方] 1.76 原版有技巧项链：需要等级 16，技能点数翻倍（新浪热血传奇官方合作站饰品表 https://games.sina.com.cn/o/z/cq/2013-10-31/1921506473.shtml ；百度百科称另有行动/攻击速度 +2，版本不一）。原版为 BOSS 掉落；**本作按用户要求 ×5、只在商城出售** [适配]。
- 占用**现有项链栏**（`EquipSlot` 的 `necklace`），无其他属性 → 与战神/圣魔/真魂等属性项链二选一，天然的取舍：练技能时戴，打怪时换回。
- 实现：`addTrain` 内 `n *= equip.necklace?.item==='skill_necklace' ? 5 : 1`（战斗开发改，一行）。
- 绑定：不可交易、不掉落、不出售给 NPC（或售价 0）。
- 难度影响：只加速技能等级提升，不加面板；但技能早 3 级会让中期更容易。9 seed sim 不佩戴，回归不变。

### 3.3 血石系统
官方资料：
- [官方/较新版本] 《热血传奇》2023-03-09「全新战具」魔血石：装备在角色界面「特殊道具」栏，30 级，每秒回 10 HP、15 MP，消耗能量，绑定不掉落，耗尽销毁；可用金币 50 万或 10 灵符兑换（盛大官网 https://cq.web.sdo.com/web4/content.aspx?id=347743 ）。
- [旧版/私服数据库] 气血石（HP）/幻魔石（MP）/魔血石（HP+MP），小/中/大，恢复量 = 持久 ×10，放装备栏右下角空格（https://www.tayewan.com/thread-2448-1-1.html 、https://zhidao.baidu.com/question/39682196.html ）。1.76 原版是否有：**未查到**。

本作方案 [适配]：
1. **新槽位** `EquipSlot` 增加 `stone`（血石栏），与双戒双镯规则无关、独立一格。
   - 装备界面：桌面放在右列靴子下方（`Panel.ts:143` 坐标表新增一项），使用 ui-art 的血石空槽切片；手机面板同列。
   - 对比面板：血石显示「剩余 HP 储量 / MP 储量」，不比较属性。
   - 存档迁移：`equip.stone` 缺省 = 空，旧档无需迁移；`eqV` 不升级（新增可选字段）。
2. **等级与数值**：

   | 等级 | HP 储量 | MP 储量 | 价格（灵符） | 佩戴等级 |
   |---|---|---|---|---|
   | 小 | 20 000 | 20 000 | 200 | 30 |
   | 中 | 50 000 | 50 000 | 450 | 35 |
   | 大 | 120 000 | 120 000 | 900 | 40 |
   | 特 | 300 000 | 300 000 | 1800 | 45 |

   参照：一瓶强效金创药 600 HP（`items-town.ts` `hp_strong`）。
3. **自动使用**：HP < 60% 或 MP < 40% 时触发；每次回复 min(储量, 最大值×15%)，冷却 2 秒（与药水 `potCd=1s` 分开计）；这样每秒最多约 7.5% 最大值，**低于**手动连喝药，避免无脑站桩。战斗中、BOSS 房都生效。
4. **耗尽**：储量 0 时保留空石（不销毁，区别于官方），可用「补充包」充能：+20 000 HP/MP = 150 灵符；或城镇药店用金币充值（每 1 000 点 = 100 金币）作为非氪金途径（待决项 P4）。
5. **与药水/快捷栏**：药水快捷栏不变，手动喝药优先；血石只是兜底。
6. **BOSS 掉落**：建议只让 40+ 副本 BOSS 低概率掉「小血石」（如 1/50），不占用已定的套装掉落表，单独一行；需要魔兽确认，不与 eg-dungeon D3/D7 规则冲突。
7. **战斗开发接口需求**：`World.tickStone(dt)`（每帧检查阈值/冷却/储量）、事件 `{type:'stone', hp, mp}` 用于飘字；储量随存档写入 `equip.stone.charge`。

### 3.4 回城石
- 现状：回城卷 `return_scroll` 读条 `RECALL_CAST=3` 秒，移动/受伤/施法打断不消耗，目的地**比奇城**（`items-town.ts` `town:'bichi'`）；地牢逃脱卷回本区域城（`townOfFloor`）；回城按钮走 `returnTownOf`，战斗中不可（`World.ts:1725`）。
- [旧版数据库] 有「回城石」，按持久计次数（tayewan 数据库表），1.76 原版是否有 **未查到**。
- 设计 [适配]：
  - **有次数的耐久物品**：10 次，用完消失；**无读条**、立即回城；冷却 30 秒。
  - **战斗中可用**（这是与回城卷的主要区别）；BOSS 房可用（离开即放弃本次挑战，BOSS 状态按现有逃离规则）；剧情/副本内若有「禁止回城」标记则不可用（目前没有此类标记）。
  - 目的地：**本区域主城**（`returnTownOf(floorIndex)`），不是新手村 —— 与「回城」按钮一致，避免 40+ 玩家被送回银杏村。用户原话的「回城」按此理解，若要求回小村需魔兽确认（待决项 P5）。
- 难度：战斗中秒逃降低死亡数；sim 不使用。

## 4. 防刷
**登录态（主要防线）**
- 余额、流水、订单只在服务端；客户端 RLS 只读。
- 购买 = Edge Function `wallet` 一次调用：同一 SQL 事务里 `balance >= price` 检查、扣款、写 ledger、写 order（带 `client_order_id` 幂等键，重复提交只发一次货）。
- 发货：客户端按 order 把物品写入当前存档槽并标记 `order.delivered_slot`；读档回滚只会丢物品，不会退灵符。
- 多标签页：以服务端余额为准；本地缓存只做显示。

**游客态（只能做到「不太容易」）**
- 扣款与发货同一次 `SaveStore.write`：先在内存改钱包 + 背包，再一次性写两个键；失败则都不写。
- 钱包与存档分开，导出/导入存档不带余额；删槽不发灵符。
- 多标签页：用 `storage` 事件 + `BroadcastChannel` 锁，第二个标签页商城只读。
- **防不住的**：直接改 localStorage、清浏览器数据再领 5000、备份 localStorage 后回滚。游客灵符因此**不能转入账号**，也不能参与任何排行。

## 5. 对难度回归的影响与隔离
| 商品 | 是否影响 9 seed / battle.test | 隔离 |
|---|---|---|
| 7 级卷轴、血石、双倍经验、经验药水 | 会显著改变死亡数与用时 | sim 不调用 |
| 技巧项链 | 会提前技能等级 | sim 不佩戴 |
| 回城石、复活符 | 会改死亡数 | sim 不使用 |
| 回城卷包、仓库扩容、外观 | 不影响 | — |
- 原则：商城逻辑放 `src/shop/*`，World 只暴露小接口；`tests/sim-lib.ts` 不 import 商城；默认存档无钱包也能跑。
- 新增 `tests/lingfu-shop.test.ts`：扣款+发货原子、余额不足、删槽不重发、导入不带余额、7 级卷轴仍乘 `summonMulAt`、技巧项链 ×5、血石阈值/冷却/储量、回城石次数与冷却。
- 每次实现后跑 9 seed，对比 battle.test 输出应**逐行不变**。
