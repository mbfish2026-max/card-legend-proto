## 3. 合击技能
共同规则（H1、H5）：
- 学习：英雄 43 级 → 白日门龙人处交对应 2 本白日门技能书 + 金条 2 根（H1）/金刚石（H5，数量未写）→ 得合击秘籍 → 放英雄包裹双击学习 → 获得「火龙之心」装英雄栏左下。
- 怒气：召出英雄后显示黄色怒槽；火龙之心储量 30000，持续补充怒槽；可拖入草药（蝎尾、鹿茸、阴阳仙草）、肉、书页、白日门技能书、火龙神品（九花玉露/九花雪露/元神丹/回气糕/补气丹）补充。
- 触发：怒槽满 → Ctrl+S 爆发，爆发期间持续消耗；主人与英雄攻击同一目标且均在攻击范围内即释放；耗尽未放出则作废。
- 冷却：无独立 CD，由怒槽重新积满决定；积满时间 **未查到**。
- 伤害数值、合击技能等级上限/升级方式：**未查到**（H5 仅提"合击等级越高效果越明显"）。

| 组合 | 名称 | 官方描述的效果特征（H5 原文概括） |
|---|---|---|
| 战+战 | 破魂斩 | 多目标强力攻击；熟练后"破防+吸血" |
| 法+法 | 火龙气焰 | 重创；之后再受"火"系技能攻击 HP、MP 剧减，等级越高越明显 |
| 道+道 | 噬魂沼泽 | 范围群毒，随等级提升越发致命 |
| 战+法 | 雷霆一击 | 较大伤害+持续状态：目标再受物理攻击伤害增大 |
| 法+道 | 末日审判 | 高伤害+目标生命力、魔法力持续流失 |
| 战+道 | 劈星斩 | 攻击目标防守弱点；麻痹；之后目标受魔法攻击更脆 |

各组合所需的两本白日门书名：官方 **未查到**（H9 有列，但与私服混写，不采用）。

## 6. 与现有数据冲突点
- `world.ts` 8 层，最高赤月；合击版内容从 40 级起，需扩到 40-47+ 段（另见 gap-vs-official §地图）。
- `units.ts` 已用 id `hero` 指主角；新增"英雄"需另起 id（如 `companion`），避免命名冲突。
- `skills.ts` 无合击概念、无怒气资源；`classes.ts` 只支持单主角。
- 等级上限需 ≥43（合击）/47（雷炎、卧龙）；现等级曲线与经验表需核对 gap-vs-official。
