# 多存档位（feat/multi-save，基线 feat/towns）
- 槽数默认 5，`Slots.setCount(n)` 可配 5–10（不会缩掉有存档的槽）。
- 存储：槽 1 = 旧键 `fcl_save_v1`（旧存档无需搬运即为槽 1，导出/导入与 e2e 种档格式不变）；槽 n = `fcl_save_v1_s<n>`；元数据 `fcl_slots_v1`（当前槽、名称、最后游玩、游玩时长）。
- 迁移：首次读元数据时若有旧档，写 `fcl_save_v1_backup`；已有备份不覆盖；删除/清档不动备份。
- 设置 `fcl_settings_v1` 全局，不分槽。
- 界面：标题「存档位（n）」→ 每格显示名称、职业、等级、层数、最后游玩、游玩时长；选择 / 新建 / 改名 / 删除（第二次点「确认删除」才删）。标题「新游戏」不覆盖当前有档的槽（换到首个空槽，全满则进存档位界面）。
- 游戏内设置面板加「切换存档」（保存后回标题存档位界面）；手机与电脑共用同一设置面板，只有一个入口。
- 游玩时长：两次自动存档间隔 <5 分钟才累计。
- 说明：仓库内未查到独立的存档导出/导入功能；存档 JSON 结构未改。
- 测试：tests/multi-save.test.ts；e2e tests/e2e/multi-save-shots.mjs（1280×720、844×390）。
