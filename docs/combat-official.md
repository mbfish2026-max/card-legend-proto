## 五、魔防（魔御 MAC，#10）

| 规则 | 官方/引擎说法 | 来源 | 实现 | [适配] |
|---|---|---|---|---|
| 魔御只减魔法、防御只减物理 | 伤害 − (目标最小魔防 + Random(最大魔防−最小魔防) + 1) − (目标最小防御 + Random(最大−最小) + 1)；「物理攻击时仅计算防御部分，技能攻击时仅计算魔防部分」 | https://www.tayewan.com/article-564-1.html （996 引擎按 64 位 M2 源码整理，称「对标盛大」）；同文 https://www.5xi.net/421.html | `mitigate()` / `damage(..., magic)` | 本作防御为单值：魔法伤害 = max(20%, 伤害 − 魔御×defFactor)，与物理同口径（区间随机 → 单值） |
| 哪些是魔法伤害 | 法师/道士技能为魔法，普攻与战士剑法（含烈火/刺杀等）为物理（引擎触发：[@Attack] 物理平砍、瞬发战士技能为物理；[@MagicStruck] 被魔法攻击） | https://www.64gm.com/thread-25384-1-1.html | 技能 stat≠atk（魔法/道术）→ magic=1；火墙落点与灼烧 magic=1；普攻、战士技能、召唤兽、怪物普攻 = 物理 | — |
| 沃玛教主 | 电火花 50% 物理 + 50% 魔法 | 见上表「沃玛教主·攻击」 | OFFICIAL.womaMagic=0.5 | 两部分各按占比分摊减免：伤害 = max(½×20%, ½伤害 − 防×f×½) + max(½×20%, ½伤害 − 魔御×f×½)；防=魔御时与旧公式一致 |
| 沃玛教主魔御 | 防 17、魔御 17 | docs/gap-vs-official.md S9 | 怪物未设 mdef 时取 def | 官方防=魔御，本作 def 22 → 魔御同 22 |
| 其它怪物魔御 | 未查到 | — | mdef 缺省 = def | [适配] 保持旧有法术伤害（以前法术也按防御减） |
| 祖玛教主火球 / 赤月地刺 / 牛魔法师等法系怪攻击是否算魔法 | 未查到可靠来源 | — | 保持物理（按防御） | 未查到 |
| 绿毒 | 不受防御影响 | 见上表「施毒·绿毒」 | ignoreDef：防御与魔御都无视 | — |
| 职业魔御成长 | 未查到 | — | 基础/成长 0（classes.ts 可选字段，未填） | — |
