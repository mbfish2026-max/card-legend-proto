## 2. 补齐方案

原则（**适配**）：
1. 先调现有物品的需求，尽量贴近官方值（官方 / 未查到 / 适配，每件都标出来）。
2. 官方确实没有对应物品的，**不编新物品**，列为例外交给待决。官方名未查到时不起名。
3. R82 里属于「主件」的那几件（铁剑、轻型盔甲、三条职业项链、大手镯、三个职业戒指）拉回 T2，T1 只留小件，避免出现「5 级一步到 13–15」的断档。

### 2.3 属性区间

本方案只改需求和来源，**不改任何属性**。属性沿用现有值（多数是官方值按 ADAPT 系数换算的，有些标了「暂定」）。降需求的物品（海魂、半月、魔法头盔、道士头盔、布鞋、鹿皮靴、紫绸靴、魔杖、银蛇、骨玉权杖）相对同档会偏强，强度**待核**，要等 sim 才能下结论。如果需要按档压低属性，属于另起的平衡任务。

### 2.4 美术图标需求（仅列出，不出图）

本方案**没有新增物品 id**，所以不需要新图标。只有在 D1 选了「独立手套槽」或 E2 选了「新增腰带」时才要补：手套槽的占位图标和装备栏 UI 格子各 1 个，新腰带每件 1 个（含 @2x）。现有的腰带 7 个图标已经有了（art/belt-icons d581c18）。

- 需求 ≤ 怪物等级 + 6（BOSS + 8），且怪物等级 ≤ 需求 + 15；

## 4. 1–30 级定性风险（没跑 sim，全部待核）
