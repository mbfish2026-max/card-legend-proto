# 5倍经验卷轴（feat/exp-scroll，未合并/未发布）

## 价格（建议值，待定）
- 常量：`src/shop/catalog.ts` 的 `EXP_SCROLL_PRICE = 300`（另有 `EXP_SCROLL_MUL=5`、`EXP_SCROLL_SEC=7200`、`EXP_SCROLL_MAX_SEC=28800`）。改价只需改这一个常量，商城价格表与提示随之变化。
- 依据：现价 回城石 100、召唤卷轴 300、技巧项链（永久）500、血石 200–1800；按 1元=10灵符，300≈30元。卷轴是一次性消耗品，单张价应低于永久项链；挂满 8 小时共 1200 灵符，与高阶血石同档。一张卷轴约 600 次击杀，折合约 3000 次普通击杀（见下方估算）。

## 计时方案
- 只在**在线游戏时间**计时：`World.step` 中 `time += dt` 之后扣减 `expScrollLeft`，在城里也会计时。打开面板或暂停时，BattleScene 不调用 step，所以不扣时间。dt 上限 0.05s，切后台回来不会一次扣掉一大段。
- 存档：`SaveData.expScrollSec`，向上取整到秒，只在剩余时间 > 0 时写入。旧存档没有这个字段，读取后为 0，即无效果。字段非法或为负值时按 0 处理；超过 8h 的值截到 8h。
- 对比真实时间戳方案（记录 `expiresAt = Date.now()+2h`）：
  - 时间戳方案会在离线时继续消耗。玩家买了卷轴后下线，回来效果已经没了，体验差。
  - 时间戳方案依赖本机时钟，改系统时间就能延长或作弊。
  - 本方案与现有 15s 自动存档配合。代价是刷新或崩溃时最多丢失约 15s 的进度。
- 到期时，日志栏显示金色「5倍经验效果已结束」，屏幕顶部中央弹出提示 3 秒。

## 续时与上限
- 效果期间再次使用：剩余时间 +2h，倍率仍为 ×5，不叠乘。
- 使用后剩余时间会超过 8h 时拒绝使用，不扣卷轴，并提示。不做截断，以免浪费卷轴。

## 经验来源与倍率关系
| 来源 | 位置 | 与卷轴的关系 |
|---|---|---|
| 击杀基础经验 killExp（含层倍率 BALANCE_EXP_MULT、等级差衰减 levelGapExpMult、EXP_LATE_MUL） | World.kill | 卷轴乘在其结果上 |
| 道心清明 clearMindMult（概率 ×2） | World.kill | 乘法，最高 ×10 |
| 5倍经验卷轴 getExpMultiplier() | World.kill | ×5 / ×1 |
| 任务/悬赏、环任务奖励 gainExp(scaledExp) | World.ts ~517、~1664 | 不受卷轴影响 |
| 伙伴经验 companionGainExp（按角色所得经验分成） | gainExp 内 | 间接随之提高 |
| EXP_LATE_CLS（战1.25/法1.25/道1.3） | 升级所需经验 | 提高需求，不影响获得 |

## 与技巧项链不冲突
技巧项链只在 `World.addTrain` 中把**技能熟练度**乘以 SKILL_NECKLACE_MUL，不涉及角色经验。卷轴只乘击杀的角色经验。两者作用于不同数值，可以同时生效，互不影响。

## UI
- 倒计时图标：DOM `#exp-badge`，显示「经验×5 h:mm:ss」，剩余不足 5 分钟时变橙色。
  - 电脑：放在挂机钮左侧（游戏坐标 1124,546，100×44）。
  - 手机：放在 `#mh-hang` 左侧 8px，92×44。
  - 面板打开或手机 HUD 隐藏时，图标隐藏。
- 浮动摇杆只响应左半屏画布上的触摸。图标是右半屏的 DOM 元素，不会触发摇杆，摇杆代码未改。e2e 已验证图标不与按钮、药水栏、技能重叠。
- 提示：电脑悬停图标显示说明，手机点按切换。背包和商城的物品提示里有使用说明、在线计时、上限和当前剩余时间。
