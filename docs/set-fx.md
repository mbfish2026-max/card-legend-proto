# P2 套装特效（feat/set-fx）：圣战/法神/天尊 4 件

## 1. 调研（origin/main 5d5ed0b）

- **机制**：`World.setCounts()` 按不同物品 id 计件（同款重复不计）→ `setBonuses()` 取满足件数的档 → `setSpecials()` 返回这些档的 `special` id。属性加成走 `equipStats()`；`special` 只是标记，**战斗中无人读取**（eg-sets.md：「数值未接入战斗」）。
- **定义**：`src/data/r14b.ts` CLASS_SETS（圣战/法神/天尊：头盔、项链、戒指、手镯）；`src/data/eg-sets.ts` 给 4 件档写 `special: shengzhan4/fashen4/tianzun4` 与 `SET_SPECIALS` 文案（标「[适配·待战斗开发]」，旧文案「普攻 5% 几率 1.5 倍伤害」与本需求不同，需改）。
- **官方描述**：skills-official.md 无三套内容；equip-3050-plan.md 只有掉落（赤月恶魔/双头金刚/双头血魔），套装加成「未曾被发现」（B4）→ 三个特效官方数值 **未查到**，全部 [适配]，严格按用户数值。
- **暴击**：`World.damage()`：`crit = canCrit && rng < (source.isHero ? critChance() : CRIT_CHANCE)`；`CRIT_CHANCE=0.15`、`CRIT_MULT=1.8`。`critChance()` = 0.15 + 被动准确加成。
- **魔耗**：`cast()` 两处：校验 `h.mp < s.mana`（L987）与扣除 `h.mp -= s.mana`（L1062）。合击英雄固定 8 魔不属于主角技能。
- **召唤物伤害**：召唤物攻击都走 `damage(target, amount, source=召唤物)`，amount 已含继承主角属性后的攻击。
- **治疗**：`heal(target, amount)`：技能治愈术/群体治愈术（L1085）、召唤重施回满（L1098）、药水 HoT（L1169）、英雄治愈术（L1340）、吸血（L1373）。另有直接加血：自然回复、物品即时回复（L903），不走 heal()。
- **模拟**：sim-lib 只把掉落装备穿到空槽，几乎凑不齐 4 件 → 需带套装变体（强制激活本职业特效）补测。

## 2. 方案（全部 [适配]，官方未查到）

| 特效 | 实现 | 说明 |
|---|---|---|
| shengzhan4 | 主角暴击率 +5%（critChance 加 0.05）；主角暴击时暴击**额外部分** ×1.5：倍率 1.8 → 1 + 0.8×1.5 = **2.2** | 「×1.5」三种读法：替换为 1.5（比现状 1.8 还弱，不合理）/ 整体相乘 2.7（最激进）/ 额外部分 ×1.5 = 2.2（取此，最保守合理）。仅主角造成的可暴击伤害。 |
| fashen4 | 主角技能耗魔 = max(1, ceil(mana × 0.9))，校验与扣除同值 | 向上取整、最低 1。 |
| tianzun4 | 召唤物（骷髅/神兽/诱惑宠物，source.summon）造成的伤害 ×1.1，乘在继承后伤害上、减防前；友方受到的 heal() 治疗 ×1.1 | 治疗范围：治愈术、群体治愈术、英雄治愈术、吸血、召唤重施回满；**不含**药水 HoT/即时药（物品固定量）与自然回复。合击英雄不是召唤物，其伤害不加。 |

- 不叠加：特效按 id 去重，同一套多穿不重复；setSpecials 每次按当前装备算，脱件/换装/读档即刷新。
