## 机制
- gap = 三项 (1 − min(1, 实有/门槛)) 的均值，封顶 GATE_GAP_CAP；按主角**实际装备**计分，每秒缓存一次。
- BOSS → 主角伤害 ×(1 + K_TAKEN·gap)；主角/召唤物/英雄 → BOSS 伤害 ×(1 − K_DEALT·gap)。连续平滑，无硬锁。
- 怪物行为不分职业，仅阈值按职业取主属性。只对表内 9 个 BOSS 生效（均为 30+ 层）；新手图豁免。
